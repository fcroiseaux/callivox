## Key Patterns & Decisions

### Authentication

- Apple Sign In via OAuth (no passwords stored)
- JWT tokens with 30-day expiry
- Keychain storage on iOS

### Privacy

- User IDs pseudonymized (SHA256) for analytics
- Location data optional
- No PII stored beyond authentication needs

### Offline Support

- Usage logs stored locally when offline
- Automatic sync when connectivity restored
- Fall back to native TTS when ElevenLabs unavailable
