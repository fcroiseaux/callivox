# Story 3.3: Suggestion Selection UI

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a CalliVox user,
I want to see AI suggestions and tap to select one,
so that I can quickly choose and speak my response.

## Acceptance Criteria

1. **Given** suggestions have been generated
   **When** the suggestions are ready
   **Then** they appear in a clear, accessible UI component
   **And** each suggestion is displayed as a tappable card/button
   **And** suggestions are readable with appropriate font size

2. **Given** suggestions are displayed
   **When** the user taps on a suggestion
   **Then** visual feedback confirms the selection (highlight/animation)
   **And** the selected text is sent to TTS for vocalization
   **And** the suggestion cards are dismissed or updated

3. **Given** suggestions are displayed
   **When** the user prefers to type their own response
   **Then** they can dismiss the suggestions
   **And** continue typing manually
   **And** request new suggestions if desired

4. **Given** new suggestions are being loaded
   **When** the loading state is active
   **Then** a subtle loading indicator is shown
   **And** previous suggestions remain visible until new ones arrive

5. **Given** the user is using VoiceOver (accessibility)
   **When** suggestions are displayed
   **Then** each suggestion is properly labeled for screen readers
   **And** selection works with VoiceOver gestures

### Critical Implementation Requirements

**FOLLOW EXISTING PATTERNS - Reference SpeechShortcutsView.swift and ControlButtonsView.swift**

The codebase has established patterns that MUST be followed:

**1. View Pattern with Service Observation:**

```swift
// SuggestionView.swift - MUST follow this pattern
import SwiftUI

struct SuggestionView: View {
    @StateObject private var suggestionService = SuggestionService.shared
    @EnvironmentObject var speechService: SpeechService

    // Optional: for generating suggestions based on current text
    var currentText: String
    var onSuggestionSelected: ((String) -> Void)?

    var body: some View {
        // View implementation
    }
}
```

**2. Suggestion Card Component:**

```swift
// Individual suggestion card - follow SpeechShortcutsView button pattern
struct SuggestionCard: View {
    let suggestion: String
    let onSelect: () -> Void

    var body: some View {
        Button(action: onSelect) {
            Text(suggestion)
                .font(.body)
                .multilineTextAlignment(.leading)
                .fixedSize(horizontal: false, vertical: true)
                .padding()
                .frame(maxWidth: .infinity, alignment: .leading)
                .background(Color(.systemGray6))
                .cornerRadius(12)
        }
        .buttonStyle(ScaleButtonStyle(scaleAmount: 0.97, pressedColor: .clear, normalColor: .clear))
        .accessibilityLabel(suggestion)
        .accessibilityHint("Double-tapez pour prononcer cette suggestion")
    }
}
```

**3. Using SuggestionService (from Story 3.2):**

```swift
// SuggestionService is already implemented as singleton
let service = SuggestionService.shared

// Observe published properties
// - service.suggestions: [String] - current suggestions
// - service.isLoading: Bool - loading state
// - service.showError: Bool - error flag
// - service.errorMessage: String - error text

// Generate suggestions
await service.generateSuggestions(for: "Comment vas-tu ?")

// Add selection to history
service.addToHistory(userMessage: selectedSuggestion, aiResponse: nil)

// Clear suggestions
service.clearSuggestions()
```

**4. Haptic Feedback Pattern:**

```swift
// Add haptic feedback on selection
private func selectSuggestion(_ suggestion: String) {
    // Haptic feedback
    let impact = UIImpactFeedbackGenerator(style: .medium)
    impact.impactOccurred()

    // Speak the suggestion
    speechService.speakText(suggestion)

    // Add to conversation history
    suggestionService.addToHistory(userMessage: suggestion)

    // Clear suggestions after selection
    suggestionService.clearSuggestions()
}
```

**5. Loading State Pattern:**

```swift
// Show loading indicator when generating
if suggestionService.isLoading {
    HStack {
        ProgressView()
            .scaleEffect(0.8)
        Text("Chargement des suggestions...")
            .font(.caption)
            .foregroundColor(.secondary)
    }
    .padding()
}
```

### UI/UX Design Guidelines

**Layout Options:**

Option A: Horizontal scrollable cards (recommended for compact display)
```
┌─────────────────────────────────────────────┐
│ Suggestions:                          [X] ↻ │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐     │
│ │ Très     │ │ Ça va    │ │ Je vais  │ ... │
│ │ bien !   │ │ bien.    │ │ bien.    │     │
│ └──────────┘ └──────────┘ └──────────┘     │
└─────────────────────────────────────────────┘
```

Option B: Vertical list (better for longer suggestions)
```
┌─────────────────────────────────────────────┐
│ Suggestions:                          [X] ↻ │
│ ┌─────────────────────────────────────────┐ │
│ │ Très bien, merci pour ta question !    │ │
│ └─────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────┐ │
│ │ Ça va bien, et toi comment vas-tu ?    │ │
│ └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

**Color Scheme:**
- Card background: `Color(.systemGray6)` - matches existing shortcuts
- Selected state: Brief scale animation via ScaleButtonStyle
- Loading state: Standard `ProgressView()` with caption
- Dismiss button: System gray with X icon
- Refresh button: System gray with arrow.clockwise icon

**Interaction Flow:**
1. User types text or receives conversation context
2. User taps "Suggestions IA" button to request suggestions
3. Loading indicator appears while generating
4. Suggestions appear as tappable cards
5. User taps suggestion → haptic feedback → TTS speaks → suggestions clear
6. OR user taps dismiss → suggestions clear → user types manually
