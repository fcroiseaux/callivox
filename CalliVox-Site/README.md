# CalliVox - Site Web Officiel

## Description
Ce dépôt contient le site web officiel de **CalliVox**, une application innovante qui permet aux personnes atteintes de troubles de la parole de retrouver leur voix grâce à une synthèse vocale personnalisée par intelligence artificielle (IA). Le site sert de vitrine pour l'application, présentant ses fonctionnalités, ses avantages et permettant aux utilisateurs de la télécharger.

## Fonctionnalités du Site
- **Présentation de CalliVox** : Explication détaillée des fonctionnalités et de l'objectif de l'application.
- **Témoignages** : Avis et expériences d'utilisateurs.
- **Téléchargement** : Liens vers les plateformes où l'application est disponible.
- **Support et Contact** : Informations pour obtenir de l'aide et contacter l'équipe CalliVox.

## Installation et Déploiement

### Prérequis
- Un serveur web (Apache, Nginx, ou autre)
- Un navigateur moderne (Chrome, Firefox, Edge...)

### Étapes d'installation
1. Clonez ce dépôt sur votre machine :
   ```sh
   git clone https://github.com/votre-repo/callivox-site.git
   ```
2. Accédez au dossier du projet :
   ```sh
   cd callivox-site
   ```
3. Déployez les fichiers sur un serveur web ou ouvrez `index.html` dans votre navigateur pour tester en local.

## Structure du Projet
```
callivox-site/
```

## Déploiement
Le site peut être déployé sur n'importe quel serveur web en plaçant les fichiers du projet dans le répertoire du serveur.
